Factory Inventory Management: Architecture

A two-tier demo app: a Vue 3 single-page app talks over HTTP/JSON to a FastAPI backend, which serves sample data loaded from JSON files into memory. There's no database, no real authentication, and nothing persists between restarts.

Frontend · Vue 3 + Vite · :3000 Backend · FastAPI + Uvicorn · :8001 Data · 7 JSON files, in memory Workshop baseline app

Data flow: one filter change

  1. User picks a filtere.g. Warehouse = Tokyo in FilterBar
  2. useFilters updatesShared refs; every view watching them reacts
  3. api.js requestGET /api/orders?warehouse=Tokyo
  4. FastAPI filtersList comprehension over in-memory data
  5. Pydantic validatesresponse_model shapes the JSON
  6. Vue re-rendersRaw data in refs → computed KPIs, charts
Language (EN/JA) is applied client-side only: useI18n swaps labels, and utils/currency.js converts USD→JPY (×150). The backend always returns English and USD.

Things worth knowing

Read-only backend

Every route is a GET. Writes the UI expects (tasks, purchase orders) have no server side yet, so there's nowhere to save data.

Hard-coded API URL

localhost:8001 is written into api.js and Reports.vue; there's no Vite proxy or environment config.

Orphan view

views/Backlog.vue exists but isn't registered in the router; backlog data shows on the Dashboard instead.
